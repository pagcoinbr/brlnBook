# BR⚡LN BOLT

Este tutorial tem como objetivo auxiliar o operador iniciante de nó Lightning (Node Runner)
na instalação independente do Bitcoin Core (bitcoind), do Lightning Network Daemon (LND)
e de algumas das ferramentas mais populares para a gestão do seu nó Lightning.

O conteúdo foi desenvolvido a partir das experiências práticas dos membros da
comunidade BR⚡LN, tomando como base a versão em inglês do projeto Minibolt:
https://v2.minibolt.info.

Ao longo deste guia, você vai aprender a:

- Entender os requisitos mínimos de hardware.
- Instalar o sistema operacional Linux Ubuntu Server.
- Criar usuários e preparar o sistema.
- Instalar e configurar o Bitcoin Core.
- Instalar e configurar o LND.
- Instalar o LNDg.
- Instalar o Thunderhub.
- Instalar o BTCPay Server.
- Instalar o Balance of Satoshis.

## Sobre a BR⚡LN

Bem-vindo ao BR⚡LN Club! Somos uma comunidade apaixonada de operadores de
nós Lightning, dedicada a promover a adoção e o entendimento do Bitcoin e da
Lightning Network.

Nosso objetivo é estudar, desenvolver e crescer em conjunto, contribuindo para o
ecossistema mais amplo do Bitcoin. Acreditamos que qualquer pessoa pode operar
um nó Lightning desde que tenha acesso ao conhecimento adequado e a
orientações claras.

Nossa missão é reduzir a curva de aprendizado e capacitar indivíduos para que se
tornem proficientes na gestão dos seus próprios nós. Ao fazer isso, ajudamos a
acelerar a adoção da Lightning Network e o seu potencial transformador para as
transações digitais.

Junte-se a nós nesta jornada. Aqui você terá acesso a recursos exclusivos,
suporte prático e a uma comunidade vibrante de entusiastas com interesses
semelhantes. Juntos, podemos causar um impacto significativo no futuro das
finanças descentralizadas e dos pagamentos digitais.
